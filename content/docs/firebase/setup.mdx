## Introduction

Firebase gives you authentication, a real-time database, cloud messaging, crash reporting and analytics — without running your own server. This guide connects a Flutter app to a new Firebase project.

## Create the Firebase project

1. Go to the [Firebase Console](https://console.firebase.google.com) and click **Add project**.
2. Give it a name (for example `enjoye-demo`) and follow the steps.
3. Google Analytics is optional — you can enable it later.

## Register your Flutter app

Inside the project, add an **Android app** with your package name, e.g. `com.enjoye.myapp`. The package name must exactly match the `applicationId` in `android/app/build.gradle.kts`.

```kotlin
// android/app/build.gradle.kts
android {
    namespace = "com.enjoye.myapp"
    defaultConfig {
        applicationId = "com.enjoye.myapp"
    }
}
```

Repeat for iOS if needed.

## The easy way: FlutterFire CLI

The official CLI downloads config files and edits Gradle files for you:

```bash
# One-time install
npm install -g firebase-tools
dart pub global activate flutterfire_cli

# Log in and configure
firebase login
flutterfire configure
```

`flutterfire configure` generates `lib/firebase_options.dart` automatically.

## Add the core package

```yaml
dependencies:
  firebase_core: ^3.13.0
```

Then initialize before running the app:

```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
  runApp(const MyApp());
}
```

<Callout type="warning" title="EnsureInitialized is required">
Any Firebase call before `WidgetsFlutterBinding.ensureInitialized()` throws an error. This line is easy to forget in `main()` — put it first.
</Callout>

## Verify the connection

Add temporary logging after initialization:

```dart
final app = await Firebase.initializeApp(
  options: DefaultFirebaseOptions.currentPlatform,
);
print('Connected to ${app.options.projectId}');
```

Run the app — if the project id prints correctly, Firebase is live.
